About Me

Profile

I am an Integrated M.S./Ph.D. candidate in Software-FinTech Convergence at Sungkyunkwan University (SKKU), Korea, working in the Computing Platforms Lab (CPL) with Prof. Hyungmin Cho. I specialize in microarchitecture and processor security; my research focuses on mesh interconnect security, side-channel attacks, and traffic-based vulnerability analysis on modern server and cloud platforms.

Research Interests

  • Microarchitecture and processor security
  • Processor interconnects, especially on-chip meshes of server and cloud processors
  • Side-channel attacks and their detection
  • Machine learning for security and data analysis
